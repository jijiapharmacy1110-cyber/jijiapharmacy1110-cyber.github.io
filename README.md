# 吉佳藥局官方網站

純靜態網站（HTML + CSS + 原生 JavaScript），可直接放在 GitHub Pages。
沒有購物車、沒有付款。商品、消息與營業狀態有兩種管理方式，擇一即可：

- **登入式管理後台（建議）**：`admin.html`，用 Google 帳號登入，資料存在 Firebase。可管理商品（含圖片）、消息、營業與服務狀態，並接收訪客的線上洽詢，另可選配 LINE 通知。設定步驟見 **`後台設定指南.md`**。先看樣子可開 `admin.html?demo=1`。
- **Google 試算表**：不需要 Firebase，設定最簡單，但沒有登入保護，也沒有線上洽詢表單。說明見下方。

`config.js` 的 `firebase` 有填就用後台；沒填就用試算表；兩者都沒填則顯示 `data/fallback.js` 的內容。

## 上線前請先放回圖片

這份檔案**不含圖片**。請把原本網站 `assets/` 裡的兩張圖放回同一位置：

- `assets/brand-mark.png`（吉字貓掌商標）
- `assets/sign-concept.png`（招牌設計示意）

沒放也不會壞版：商標位置會顯示綠底「吉」字，招牌位置顯示文字框。

## 替代方案：用 Google 試算表管理商品

### 第一次設定（約 10 分鐘）

1. 在 Google 雲端硬碟建立一份新的試算表，建立三個分頁：`商品`、`消息`、`設定`。
2. 每個分頁用「檔案 → 匯入 → 上傳」匯入 `sheet-templates/` 裡同名的 CSV（匯入位置選「取代目前的工作表」）。
3. 「檔案 → 共用 → 發布到網路」：選擇分頁（例如 `商品`）、格式選「逗號分隔值 (.csv)」，按發布，複製網址。三個分頁各做一次。
4. 把三個網址貼到 `config.js` 的 `sheets` 裡，存檔後上傳到 GitHub：

```js
sheets: {
  products: 'https://docs.google.com/spreadsheets/d/e/……/pub?gid=0&single=true&output=csv',
  news:     'https://docs.google.com/spreadsheets/d/e/……/pub?gid=111&single=true&output=csv',
  settings: 'https://docs.google.com/spreadsheets/d/e/……/pub?gid=222&single=true&output=csv'
}
```

之後改試算表就會更新網站，不必再動程式。Google 發布的內容約每 5 分鐘更新一次，所以修改後要等幾分鐘才看得到。

> 發布到網路後，知道網址的人都能讀到這三個分頁的內容。請只放要公開的資料，成本、供應商報價、客戶資料不要寫在這份試算表裡。試算表的**編輯權限**只給負責更新的人，並開啟 Google 帳號兩步驟驗證。

### 「商品」分頁欄位

| 欄位 | 填法 |
| --- | --- |
| 編號 | 自訂，例如 `2F-07`。會出現在洽詢訊息裡，方便門市對照 |
| **顯示** | `是` 才會出現在網站；`否` 或空白就隱藏 |
| **已審核** | `是` 才會出現。建議由合規審核人填，更新內容的人不要自己填 |
| 樓層 | `1F` 或 `2F` |
| 類別 | 自訂，例如 保健食品、居家醫材、爬蟲飼養、造景材料。篩選按鈕會自動產生 |
| 名稱 | 必填 |
| 品牌 | 選填。未正式授權或合作前請留空 |
| 簡介 | 卡片上的一兩句說明 |
| 規格 | 選填，例如 `60×40×40 cm`、`30 包／盒` |
| 適用物種 | 選填，用頓號分隔，例如 `守宮、蜥蜴`。會自動產生「依物種找」篩選 |
| 狀態 | 選填：`已啟用`／`洽詢中`／`規劃中`／`暫停` |
| 價格 | 選填。填數字會顯示成 `NT$ 1,280`；也可填文字如 `依規格洽詢` |
| 圖片 | 選填。把圖檔放進 `assets/products/` 後填檔名（如 `uvb-lamp.jpg`），或貼 `https://` 圖片網址。留空顯示類別示意圖 |
| 精選 | `是` 會出現在首頁（最多 6 個） |
| 排序 | 數字小的排前面；沒填排最後 |
| 注意事項 | 點開詳情時顯示 |

**要同時符合「顯示＝是」和「已審核＝是」才會公開。** 另外有兩道自動防呆，就算兩欄都填「是」也不會顯示：

- 類別或名稱含「藥品、成藥、處方、指示藥、西藥、管制藥」等字詞（藥品不放進商品目錄）
- 文案含疑似醫療效能字詞，如「治療、根治、療效、降血壓、降血糖、三高、抗癌、保證有效」

防呆只是輔助，抓不到所有不當用語，仍需要人工審核文案。

### 預覽模式

在網址後面加 `?preview=1`（例如 `products.html?preview=1`），會顯示試算表**所有列**，被擋下的項目用紅色虛線標出並說明原因。用來在公開前檢查，或查「為什麼這個商品沒出現」。

注意：預覽模式不是密碼保護，知道這個參數的人都看得到試算表裡的全部內容。

### 「設定」分頁

改「值」那一欄即可，留空就用 `config.js` 的預設值。

- `營業狀態`：`籌備中`／`已開幕`／`暫停營業`。改成「已開幕」後，全站的籌備提示會消失，「預計營業時間」變成「營業時間」。
- `處方箋與慢箋`、`特寵寄宿` 等 9 個服務：`已啟用`／`洽詢中`／`規劃中`／`暫停`。`特寵寄宿` 設成「暫停」時，寄宿洽詢表單會停用。
- `LINE連結`：貼上後，全站的 LINE 按鈕才會出現。
- `一樓經營主體`、`二樓經營主體`：登記完成後填寫，顯示在「關於吉佳」。

### 「消息」分頁

`日期` 請用 `2026-11-15` 格式。`顯示＝是` 才公開，`置頂＝是` 會排最前面。

### 不想用 Google 試算表

`config.js` 的三個網址留空，直接編輯 `data/fallback.js`，欄位名稱與試算表相同。

## 這個做法的限制

- 這是「公開試算表 + 靜態頁面」，不是有帳號權限的後台系統。隱藏的列雖然不會顯示在網站上，但仍在公開的 CSV 裡，懂技術的人讀得到。
- 使用試算表時，寄宿洽詢表單不會把資料送到任何地方，只是幫訪客整理成一段文字，由訪客自己傳給門市。要讓洽詢直接進後台並通知 LINE，請改用登入式管理後台。
- Google 試算表若暫時讀不到，商品區會顯示「暫時無法載入，請電話洽詢」，其他內容照常顯示。

## 部署到 GitHub Pages

把這個資料夾的所有檔案放到 `jijia-pharmacy-web` 儲存庫根目錄（`index.html` 要在最外層），Settings → Pages → Deploy from a branch → `main` / `(root)`。

本機預覽：在資料夾內執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000`。直接雙擊 HTML 檔也能看，但接了試算表後需要用這個方式才讀得到資料。

## 上線前請確認

規劃書第 10、14 章列的項目仍待店方確認，網站目前都以「籌備中／規劃中／確認後公告」呈現：

- 電話、地址、營業時間、藥師服務時段、二樓開放時段
- 一樓與二樓的正式經營主體
- 各項服務是否已取得許可、可以改為「已啟用」
- Instagram／Threads 帳號是否正確，LINE 官方帳號連結

- 商品圖片與品牌的使用授權
